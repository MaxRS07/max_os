# MAX OS

## A pure-rust hobbist operating system built for RISC-V. 

This is by far my biggest (and most fun) project yet! The planned scope covers:

- Kernel space
    - Allocation
    - Threading / Scheduling
    - Filesystem with custom formatting and thread locking
    - Input device drivers
    - GPU resource management, buffering
    #### TODO
    - Networking
    - GPU hardware acceleration for 3D rendering
    - Audio driver
    - Adaptable for ARM
- Library space
    - Custom standard library
    - Graphics lib for 2d and 3d rendering
